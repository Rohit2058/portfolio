Project Status Report: Rohit Kumar Sah Portfolio Website

Project Overview

Building a freelance portfolio website for Rohit Kumar Sah (BE Electrical Engineering, TU 2025, Instructor at Banepa Polytechnic Institute) using Astro + plain CSS with a static site generation approach.

Deployment target: GitHub Pages at https://rohit2058.github.io/portfolio/ with base path /portfolio/

Tech Stack & Architecture

  • Framework: Astro (static site generation, zero JS by default)
  • Styling: Plain CSS with CSS custom properties for theming
  • Content: Markdown content collections via astro:content (site-copy, projects, samples)
  • Fonts: Self-hosted (Space Grotesk, Inter, JetBrains Mono) via @font-face
  • Theme: Engineering blueprint — navy #0B1220, amber #FFB700, cyan #4CC9F0
  • Theme system: Light/Dark/System toggle with localStorage persistence + system preference listener
  • Animations: IntersectionObserver scroll-reveal, SVG animations (damped oscillation, blueprint grid)
  • CI/CD: withastro/action + actions/deploy-pages for GitHub Pages
